# Viva Bem — Saúde e Bem-Estar

## Sobre o Projeto

O **Viva Bem** é um projeto voltado à saúde e ao bem-estar, com o objetivo de centralizar informações, conteúdos de conscientização e dicas de saúde em uma plataforma acessível ao público geral.

## Objetivo de Desenvolvimento Sustentável (ODS)

**ODS 3 — Saúde e Bem-Estar**

Promover a saúde e o bem-estar, contribuindo para a conscientização e facilitando o acesso a informações relacionadas à saúde.

## Problema

A dificuldade de encontrar informações sobre saúde em um único lugar pode dificultar o acesso a conteúdos de conscientização, orientações gerais e informações sobre unidades de tratamento.

O projeto busca reunir esses recursos em uma plataforma intuitiva e acessível.

## Público-Alvo

Público geral interessado em informações sobre saúde, bem-estar, prevenção e cuidados pessoais.

## User Stories

### Como usuário comum

**Eu quero** ter acesso a conteúdos de conscientização, dicas de saúde e informações para localizar unidades de tratamento.

**Assim,** posso encontrar informações de forma centralizada e esclarecer minhas dúvidas sobre saúde e bem-estar.

## Requisitos

* Interface limpa, intuitiva e acessível.
* Layout responsivo e otimizado para diferentes dispositivos.
* Organização das informações para facilitar a navegação.
* Acesso simplificado aos conteúdos e às funcionalidades da plataforma.

## Funcionalidades

* **Login e cadastro:** acesso à plataforma e criação de conta.
* **Pesquisa:** busca por conteúdos e informações disponíveis.
* **Informações sobre saúde:** acesso a conteúdos gerais de saúde e bem-estar.
* **Calculadora de IMC:** cálculo do Índice de Massa Corporal com base nos dados informados pelo usuário.
* **Localização de unidades de tratamento:** acesso a informações que auxiliem na busca por unidades de atendimento.

## Como Executar o Projeto

### Pré-requisitos

* [Node.js](https://nodejs.org/) instalado.
* Gerenciador de pacotes npm.

### Passos para execução

1. Clone o repositório:

   ```bash
   git clone URL_DO_REPOSITORIO
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd nome-da-pasta
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

5. Acesse o endereço local exibido no terminal, geralmente `http://localhost:5173`.
